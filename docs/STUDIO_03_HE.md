# Studio 0.3 — המשך שדרוג סביבת העבודה

## מה נוסף
- גלריה מעוצבת של שמונה תבניות: מאמר, פרק בספר, דף לימוד, מערך שיעור, סיכום פגישה, הצעת פרויקט, מכתב רשמי ויומן כתיבה.
- כל תבנית יוצרת מסמך חדש עם כותרות וסגנון גופן מתאים.
- חיפוש בספרייה לפי שם ותוכן, מיון לפי עדכון אחרון או שם וספירת תוצאות.
- גיבוי הספרייה לקובץ `.toklibrary`, כולל הערות ונקודות שחזור.
- שחזור מוסיף עותקים חדשים; אינו מחליף את המסמכים הקיימים. מזהים חדשים מונעים התנגשויות.
- בדיקת מבנה הגיבוי, סינון HTML, הגבלת גודל וקיבולת לפני הוספה. כתיבת האחסון מתבצעת לפני עדכון הממשק.
- חלון נתוני מסמך: מילים, תווים, פסקאות, כותרות, טבלאות וזמן קריאה משוער.
- הפעולות החדשות זמינות גם דרך Ctrl+K.

## השראה מפרויקטים
נבדקו [Outline](https://github.com/outline/outline) ותיעוד [התבניות שלו](https://docs.getoutline.com/s/guide/doc/templates-GP6DXgRtxl), וכן [Joplin](https://github.com/laurent22/joplin) בנוגע לניהול מסמכים מקומי וחיפוש. אלו מקורות השראה מוצרית בלבד: לא הועתק קוד ולא נוספו חבילות או מנועי עריכה שלהם.

## מגבלות
הספרייה עדיין מוגבלת לעשרה מסמכים ולמכסת האחסון הקיימת. כדי לשחזר גיבוי של ספרייה מלאה יש לגבות תחילה את הספרייה הנוכחית ולפנות מקום. השחזור אינו מיזוג שינויים. אין גיבוי ענן או הצפנת קובץ. מגבלות העימוד ופורמטי הייבוא מגרסה 0.2 עדיין חלות. גודל ה-HTML אינו גודל מתקין Electron.

## אימות
`npm test`, `npm run build`, `tests/browser-smoke.cjs`, `tests/library-browser.cjs`.
