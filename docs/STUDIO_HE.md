# TypesetOK Studio 0.2

גרסה זו מחליפה את עורך הטקסט הפשוט בסביבת עריכה מעוצבת ישירות על הדף. מתקין Windows החדש הוא `TypesetOK-0.2.0-Windows-x64-Setup.exe`.

## מה חדש

- סרגלי בית, הוספה, פריסה וסקירה עם אייקוני SVG מקומיים, מצבי כפתורים וקיצורי מקלדת.
- דף מרכזי לעריכה ישירה: מודגש, נטוי, קו תחתון, קו חוצה, צבע טקסט והדגשה בצבע לבחירה.
- סגנונות טקסט רגיל, כותרת ראשית, כותרת משנה וציטוט; רשימות ממוספרות ותבליטים, יישור והזחות.
- טבלאות: בחירת שורות ועמודות, הוספת שורה/עמודה, מחיקת שורה ומחיקת טבלה. מקמי סמן בתא לפני עריכת המבנה.
- ארבע תבניות עיצוב למסמך: מערכתי, ספר, מודרני ושירה.
- ספריית עבודה מקומית של עד עשרה מסמכים, החלפה ביניהם, שכפול ומחיקת טיוטה באישור.
- הערות כלליות למסמך, שנשמרות בקובץ ואינן מודפסות; הן אינן הערות מעוגנות למילים.
- עד חמש נקודות שחזור מקומיות לכל מסמך. שחזור מחזיר תוכן ועיצוב וניתן לביטול.
- היסטוריית ביטול ושחזור לטקסט ולעיצוב; עד 60 רשומות או כארבעה מיליון יחידות UTF-16.
- מתאר כותרות לחיץ, יעד כתיבה ומד התקדמות, ספירת מילים ותווים ופרטי הבחירה.
- לוח פעולות בחיפוש עם Ctrl/⌘+K, ומצב ריכוז שמסתיר את החלוניות.
- חיפוש והחלפה, תווים מיוחדים, תאריך, קו מפריד ומעבר מקטע ידני.
- סקירת מבנה בסיסית: מסמך ריק, כותרת חסרה, רווחים כפולים ופסקאות ארוכות. זו אינה בדיקת לשון או preflight לדפוס.
- כלי ניקוד וטעמים ונרמול Unicode; על בחירה הכלי מחליף את הטקסט הנבחר, ועל מסמך שלם הוא פועל בתוך צומתי הטקסט.
- ייצוא TXT ו-HTML מעוצב, הדפסה ושמירה כ-PDF דרך חלון ההדפסה.

## קבצים ותאימות

פורמט העבודה החדש `.tokdoc` שומר HTML מסונן, שם, הגדרות עיצוב, הערות ויעד כתיבה. אפשר לפתוח גם `.tokdraft` מהגרסה הקודמת ו-TXT. ייבוא טיוטה קודמת ממיר כותרות ומעברי מקטע בלי להשליך את הטקסט. היסטוריית הביטול ונקודות השחזור הן מקומיות ואינן נכללות בקובץ המיוצא.

טיוטה אחרונה של הגרסה הקודמת מועברת למסמך Studio בעת ההפעלה הראשונה, אם אין עדיין ספריית Studio. נתון הטיוטה הישן נשמר במפתח האחסון המקורי. במקרה של ספרייה פגומה נשמר הקלט הישן ואוטו-שמירה לספרייה מושבתת; עדיין אפשר לשמור קובץ מתוך הסשן החדש. מחיקת נתוני היישום עלולה להסיר מסמכים מקומיים, ולכן יש לשמור גם קבצים.

החלפה כוללת שומרת את מבנה העיצוב ופועלת בכל מקטע טקסט. ביטוי שחוצה שני עיצובים שונים אפשר למצוא ולהחליף בודד דרך ״הבא״ ו״החלפה״; ההודעה לאחר החלפת הכול מסבירה את המגבלה.

## עיצוב וביצועים

סרגל עליון קבוע, תפריטי כלי עבודה, ספריית מסמכים מימין וחלונית מאפיינים משמאל. מצב כהה משנה את מעטפת העבודה ושומר על דף לבן. חלון צר מצמצם או מסתיר את חלונית המאפיינים, וניתן להמשיך להשתמש בכלי העריכה העליונים.

הממשק משתמש ב-HTML/CSS/JavaScript בלבד, ללא תלויות runtime או גופנים מרוחקים. מתקין Electron כולל את מנוע Chromium ולכן גדול יותר מקובץ ה-HTML. לא נמדדה כאן תקרת צריכת RAM, ואין הבטחת ביצועים לאלפי עמודים.

קלט מסמך מעוצב מוגבל ל-500,000 יחידות UTF-16 ול-8,000 צומתי תוכן. הספרייה מוגבלת לעשרה מסמכים ולעד כ-3.5 מיליון יחידות אחסון סריאליות; כשל מכסה מוצג במפורש. שמירה, נתונים סטטיסטיים והיסטוריית הקלדה מושהים כדי להפחית עבודה בזמן הקלדה. בניגוד לתצוגה המקוצרת הישנה, המסמך הנוכחי כולו ניתן לעריכה, בכפוף למגבלות הקלט.

## בטיחות ותיחום

HTML מייבוא או מהדבקה עובר רשימה מצומצמת של תגיות ועיצוב. סקריפטים, אירועים, טפסים, מסגרות, תמונות וכתובות חיצוניות אינם נשמרים בתוכן. שדה הגופן והצבע אינם מאפשרים CSS פעיל; גודלי גופן מיובאים מוגבלים. CSP ממשיך לחסום חיבורים לרשת וסקריפטים שאינם של היישום. מעטפת Electron מבודדת וללא גשר הרשאות קבצים מהעורך.

עדיין אין חיבור למנוע Rust, קבצי `.tok`, DOCX, מסגרות טקסט רב־תזרימיות או PDF/X מקצועי. הדף מתרחב עם התוכן; הסרגל הוא סימון חזותי, אינו כלי גרירת שוליים. חלוקת דפים פיזיים מתבצעת בהדפסת הדפדפן. אין כאן טענה שהתוכנה מחליפה תוכנת קדם-דפוס בשלה.

## בדיקות

חמש בדיקות המודל הקיימות ממשיכות לעבור. בדיקת Chromium כוללת עיצוב בחירה, ביטול/שחזור, מבנה טבלאות, נקודות שחזור, הערות, ייצוא וייבוא בקובץ, סינון קלט זדוני, חיפוש והחלפה, גודל נייר, מצבי תצוגה, לוח פעולות, שכפול, שחזור אחרי רענון ותאימות לפורמט הקודם. בוצעה בדיקה חזותית ברוחב 1600 ובדיקת תפעול ברוחב 1100. הבנייה ל-Windows מתבצעת ב-GitHub Actions.
