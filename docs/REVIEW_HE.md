# סקירת TypesetOK — סבב ראשון, 2026-10-01

> עדכון: זהו דוח הסבב הראשון. העורך החדש ומעטפת Electron המבודדת מטפלים בחלק מפערי הממשק וההרשאות; ראו [מדריך הגרסה](LIGHT_EDITOR_HE.md). פערי ליבת Rust ו־PDF עדיין רלוונטיים.

## תמצית

זהו אב־טיפוס לתוכנת עימוד עברית, ולא אתר. קיימת חלוקה לשבע ספריות Rust ולחמישה רכיבי TypeScript. יש אלגוריתמים, מודל מסמך, אחסון ו־CLI; הממשק עדיין אינו עורך מחובר מקצה לקצה. טענות README קודמות לגבי מוצר מלא, PDF/X מאומת, 120 FPS ו־zero-copy לא נתמכו במימוש שנבדק.

נוספו בדיקות רגרסיה לקלטי תקיפה ולמבחן עומס קטן, וכן workflow לבדיקות Rust ב־Linux וב־Windows. דחיית נתיבי ZIP היא הקשחת פורמט: הפותח הנוכחי טוען לזיכרון ולא מחלץ לקבצים, ולכן לא נטען שהייתה בו כתיבת path traversal לדיסק.

## סדר העבודה הבא

1. **Electron והרשאות קבצים — גבוה:** `main.ts` מקבל נתיבי קלט/פלט מה־renderer ללא אימות שולח וללא בחירה מאושרת בתהליך הראשי. להוסיף הרשאות דרך דיאלוגים, בדיקת sender/frame, מניעת ניווט וחלונות חדשים, הגבלת פלט/זמן/מקביליות של תהליך ה־CLI וטיפול באירוע `error`. `contextIsolation`, sandbox ו־`nodeIntegration: false` כבר קיימים, אך אינם מחליפים את הבדיקות האלה.
2. **מסלול בנייה וממשק עובד — גבוה:** חסרים `tsconfig.json` ראשי וכניסת HTML; מסך fallback מציג טענות הצלחה קשיחות. להשלים bundling, חיבור preload לתפריטים ומימוש `tok:send-command`, פתיחה, עריכה, שמירה ו־Undo/Redo אמיתיים. נתיב ה־CLI ב־Electron עדיין קשיח למחשב Windows מסוים.
3. **טיפוגרפיה ו־PDF — גבוה:** לחבר את rustybuzz וגופן אמיתי למסלול העימוד, להטמיע גופן עברי ב־PDF, לתקן מיפוי גליפים, לבדוק ניקוד וטעמים ו־BiDi, ולהעביר preflight חיצוני לפני הבטחת PDF/X. נדרשות בדיקות חזותיות של קובצי הפלט.
4. **שמירה ועמידות — גבוה:** לבדוק הפסקת תהליך בכל שלב שמירה, החלפה ב־Windows וניקוי קבצים זמניים; תאריכי ברירת המחדל במניפסט קשיחים. לבחון סנכרון תיקייה ותקינות מזהי המסמך לאחר טעינה.
5. **אבטחת תצוגה ותלויות — גבוה:** `tok-viewer` מכניס `htmlContent` ל־`innerHTML`; נדרשים גבול אמון ברור, סינון תוכן ו־CSP. לבדוק ולעדכן תלויות Rust ו־Electron באמצעות סריקת advisory; לא בוצעה בסבב זה סריקת CVE ולכן אין כאן אישור להיעדר פגיעויות בתלויות.
6. **ביצועים וחוויית שימוש:** מבחני ספרים אמיתיים, סנכרון טקסט ומפרשים בין עמודים, רינדור וירטואלי עם מזהי עמוד לא רציפים, מצב מסמך לא שמור, התאוששות משגיאות, קיצורי מקלדת ונגישות.

## גבולות הסקירה

סקירת קוד ובדיקות Rust ממוקדות אינן בדיקת חדירות מלאה. מגבלות ZIP מצמצמות הקצאה בלתי מוגבלת אך אינן מגבלת זיכרון קשיחה לתהליך: JSON ומודל המסמך מוסיפים תקורה. לא בוצעו בדיקה חזותית של Electron, בדיקת PDF/X חיצונית או ניסויי נפילת מתח. CI של Windows צריך לרוץ ב־GitHub כדי לאמת שם התנהגות.


## אימות מקומי

`cargo test --workspace --locked` עבר ב־Linux: **36 בדיקות, מתוכן 8 חדשות**. הבדיקות החדשות מכסות מסגרות IPC פגומות וגדולות, escaping לתוויות עמוד, ארכיב עם מניפסט גדול, שמות נכסים לא תקינים, הגבלת קריאה ומבחני CLI קטנים/שגויים. לא הורץ כאן ממשק Electron.

ספריית ZIP חושפת רשומות לפי שם ועלולה לאחד שמות כפולים; מגבלת מספר הרשומות מתייחסת לרשומות שהיא חושפת. אין בסבב זה דחייה עצמאית של כפילויות או מנתח ZIP חלופי.
