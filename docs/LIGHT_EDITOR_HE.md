# TypesetOK — סביבת כתיבה קלה

פתחי את `TypesetOK.html` בדפדפן במחשב. אין צורך בשרת, חשבון, התקנה או חיבור אינטרנט. לשמירת גיבוי לחצי על **שמירת קובץ**. הקובץ שנוצר הוא `.tokdraft` וכולל טקסט והגדרות עיצוב; אפשר לפתוח אותו מחדש בעורך.

## האפשרויות שנוספו

| --- | --- |

| עריכה — 9 | ביטול; שחזור; בחירת הכול; חיפוש מילולי; ספירת התאמות; מעבר להתאמה הבאה; החלפת התאמה; החלפת הכול; הפעלה/כיבוי איות הדפדפן |

הגדרות העיצוב משפיעות על כל המסמך. פעולות ניקוי הטקסט פועלות על הבחירה, או על כל המסמך כשאין בחירה; ניתן לבטל אותן. התמיכה באיות תלויה בדפדפן ובמילונים המקומיים שלו. נרמול NFC אינו מימוש של תקן ת״י 6100.

## קלילות ופרטיות

- HTML, CSS ו-JavaScript בלבד; אין ספריות runtime, שירותי AI, גופנים חיצוניים, תמונות או בקשות רשת.
- קובץ עצמאי בגודל כ־34KB לפני דחיסה. גודל הקובץ אינו מדידת RAM.
- עד 500,000 יחידות UTF-16 לטקסט במסמך; עד 4MB לקובץ ייבוא.
- היסטוריית עריכה מוגבלת ל־60 רשומות ולכ־4 מיליון יחידות UTF-16, לא היסטוריה בלתי מוגבלת. שינויי עיצוב אינם כלולים בהיסטוריית הטקסט.
- תצוגה מקדימה מושהית ב־180ms ושמירה מקומית מושהית ב־700ms, כדי להימנע מעבודה בכל הקלדה.
- תצוגה ארוכה מוגבלת ל־12 מקטעים, 30,000 יחידות טקסט ו־300 בלוקים למקטע. מוצגת הודעה כאשר התצוגה מקוצרת. ייצוא HTML כולל את כל התוכן.
- שמירה אוטומטית היא טיוטה אחת בדפדפן, לא ספריית מסמכים. מחיקת נתוני דפדפן או שימוש בחלון פרטי עלולים להסיר אותה. כשל בשמירה מוצג למשתמשת.
- התוכן מוכנס לתצוגה כטקסט, לא HTML פעיל; קובצי טיוטה עוברים אימות פורמט, טיפוסים וטווחים.
- CSP חוסם רשת וסקריפטים בלתי מורשים. מעטפת Electron החדשה מפעילה sandbox, מבודדת את ההקשר, אינה חושפת preload/IPC וחוסמת ניווט, חלונות חדשים והרשאות.

## מגבלות חשובות

זו סביבת עריכה קלה חדשה בתוך הפרויקט, לצד הליבה הקיימת. אין עדיין סנכרון עם `.tok`, מנוע Rust, פירושים רב־תזרימיים או עימוד ספר מקצועי. העמוד בתצוגה מתרחב כאשר יש בו טקסט רב; השתמשי במעבר עמוד (`---` בשורה נפרדת) או בעימוד של הדפדפן בעת הדפסה. המספור מציין מקטעים ידניים, ואינו מספור מאומת של דפי ההדפסה הפיזיים.

כאשר התצוגה מקוצרת, כפתור ההדפסה מפנה לייצוא HTML מלא ולהדפסה שלו. PDF מתקבל דרך בחירת "שמירה כ-PDF" בחלון ההדפסה, ולא כמנוע PDF/X לדפוס. הגופנים תלויים במערכת ההפעלה. ההפעלה השולחנית כבדה יותר בגלל Electron; גרסת HTML היא הדרך הקלה ביותר להפעלה. גרסת Electron שבתלויות ירושה מהפרויקט וזקוקה לשדרוג ובדיקת advisories לפני הפצה רחבה; לא בוצעה כאן סריקת פגיעויות בתלויות.

## אימות

- `npm test`: חמש בדיקות מודל, כולל קלט פגום, היסטוריה מוגבלת וכלי עברית.
- `npm run build:desktop`: בניית HTML והידור TypeScript של מעטפת Electron.
- בדיקת דפדפן אמיתי: הפעלה מקובץ ללא שרת, מניעת הרצת HTML בטקסט, חיפוש/החלפה, ביטול/שחזור, שינוי גודל עמוד, הורדה ופתיחת טיוטה, ערכת צבעים, מצב ריכוז, תצוגה מוגבלת, ייצוא מלא ושחזור לאחר רענון.
- בדיקה חזותית ברוחב 1440px. מעטפת Electron עצמה לא הופעלה; אין כאן אימות Windows.

בדיקת הדפדפן נמצאת ב־`tests/browser-smoke.cjs`; ניתן להריץ עם Playwright ו-Chromium מותקנים. `TOK_PLAYWRIGHT` ו־`TOK_CHROMIUM` מאפשרים לציין מיקומים חלופיים.
